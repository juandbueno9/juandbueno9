### Sobre mí

Trabajo en el área de infraestructura y sistemas de una cooperativa financiera en Colombia. Mi día a día es mantener servidores Linux en AWS funcionando, seguros y monitoreados, y automatizar todo lo que se repite.

- 🖥️ Administro servidores **Ubuntu en AWS** con Nginx, systemd/pm2, Docker y PostgreSQL/MySQL.
- 📈 Implementé un stack de **observabilidad**: Prometheus, Grafana, Loki, Alertmanager y Blackbox, con auditoría de accesos SSH.
- 🔐 Integro **SSO con Keycloak** y aplicaciones en **Microsoft Entra ID** con permisos mínimos.
- ⚙️ Automatizo con **Bash y Python**: backups, alertas, reportes y tareas programadas con cron.
- 🌱 Ahora estoy aprendiendo **Terraform** y **Ansible**.

*I'm an IT infrastructure professional based in Colombia: Linux, AWS, Docker, monitoring and automation. Open to infrastructure / DevOps / SysAdmin roles.*
