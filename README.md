### 🧭 Principios con los que trabajo

```text
✔ Cambios reversibles   → todo despliegue tiene respaldo y plan para revertirlo
✔ Mínimo privilegio     → solo lectura por defecto, permisos por aplicación
✔ Secretos fuera de git → .env.example sí, .env nunca
✔ Todo documentado      → si no está en el README, no existe
✔ Monitorear primero    → la alerta llega antes que la queja del usuario
```
